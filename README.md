# 2028 대입전형 가이드

2028학년도부터 새로 적용되는 고교학점제와 내신 5등급 절대평가 체계에 맞춰,
서울 주요 15개 대학의 입학전형 정보를 한눈에 비교하고 이해할 수 있도록 만든 웹 프로그램입니다.

## 주요 기능

- 대학별 전형 정보 조회 및 필터 (수시/정시, 전형 방식, 수능 최저 여부)
- 전형 비교표 (최대 5개 나란히 비교)
- 5등급제·고교학점제 개념 해설

## 사용 기술

- HTML / CSS / JavaScript
- 데이터: JSON 파일 (각 대학 공식 공시 자료 기반)

## 실행 방법

1. 저장소를 클론합니다.
2. VS Code에서 폴더를 열고 Live Server로 `index.html`을 실행합니다.

## 데이터 출처

각 대학 입학처 공식 공시 자료 — 2028학년도 대학입학전형시행계획

본 프로그램의 정보는 참고용이며 합격을 보장하지 않습니다.
