# OFGONG - 2028 대입전형 정보 플랫폼

2028학년도 대입부터 처음 적용되는 고교학점제와 내신 5등급 절대평가 체계에 맞춰, 각 대학의 대입전형을 체계적으로 정리하고 학생이 이해하기 쉬운 형태로 제공하는 플랫폼입니다.

## 프로젝트 개요

- **주 사용자**: 2028학년도 대입 대상 고교 1,2학년 학생
- **보조 사용자**: 학부모, 진학 담당 교사
- **초기 범위**: 서울의 주요 15개 대학
- **주요 기능**: 전형 검색, 비교, 전략 해설, 개념 사전

## 프로젝트 구조

```
ofgong/
├── backend/              # 백엔드 (Node.js/Express)
├── frontend/             # 프론트엔드 (React)
```
