# OFGONG Frontend

React + Vite 기반 프론트엔드 애플리케이션

## 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build

# 빌드 결과 미리보기
npm run preview
```

## 페이지 구조

- `/` - 홈페이지
- `/universities` - 대학 정보
- `/admissions` - 전형 검색
- `/strategy` - 전략 추천
- `/guide` - 개념 사전 (5등급제, 고교학점제)

## 컴포넌트

- `Navbar` - 네비게이션 바
- `Footer` - 푸터
- 각 페이지별 컴포넌트

## 스타일

- Tailwind CSS 사용
- 모바일 반응형 지원

## 테스트

```bash
npm test
```
